# Badge

Small status pill. Monochrome by default; color only when it means something.

- 22px, `radius-full`, `caption` in bold (700).
- Neutral tones: `neutral` (`fill` + `text-secondary`), `outline` (`border` edge), `solid` (`primary`).
- Status: `success`, `warning`, `danger` - tinted background, text in the tone, and a leading dot. The word carries the meaning.

The consumer provides: 1-2 words as children and `tone`.
