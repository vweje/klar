# Icon

Klar's line icons: 24px grid, 2px stroke, round caps, `currentColor` - heavy enough to match the bold type.

- Default size 16px in UI, 18-20px when the icon stands alone. Inherits the text color.
- Decorative by default (`aria-hidden`); provide a `label` when the icon stands alone and carries meaning.

Names: chevron-right, chevron-down, arrow-right, search, check, xmark, plus, more, home, inbox, folder, calendar, chart, person, settings, bell, lock, info.
