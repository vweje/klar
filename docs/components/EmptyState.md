# EmptyState

What you see when a list, table, or page is empty - always with a way forward.

- Dashed `border-strong` frame, `radius-lg`, centered. Icon in a small raised tile, 16px title at weight 800, description in `text-secondary`.
- `action` holds 1-2 buttons: the primary action on the right.

The consumer provides: `title` (what is missing), `description` (what you can do), `icon`, and `action`.

Do: be specific ("No tasks yet"), not "No data".
